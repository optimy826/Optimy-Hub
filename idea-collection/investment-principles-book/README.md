# 투자의 정석 (가제) — 책 집필 프로젝트

사회초년생이 된 자녀에게 물려주고 싶은 투자 원칙을, 3년에 걸쳐 천천히 기록해 발행하는 개인 집필 프로젝트입니다.

## 폴더 안내

| 파일 | 역할 |
|---|---|
| [00-기획서.md](./00-기획서.md) | 왜 쓰는지, 누구를 위한 책인지, 3년 로드맵 |
| [01-기술명세서.md](./01-기술명세서.md) | 집필 방식·파일 규칙·버전관리·보안 주의사항 |
| [02-목차초안.md](./02-목차초안.md) | 부/장 단위 목차 초안 (계속 수정됨) |
| `templates/chapter-template.md` | 새 장을 쓸 때 복사해서 시작하는 템플릿 |
| `chapters/` | 실제 원고 (장별 .md 파일) |

## 시작하는 법

1. `02-목차초안.md`에서 쓸 장을 고른다.
2. `templates/chapter-template.md`를 `chapters/` 밑에 복사하고 파일명을 `01-장-제목.md` 형식으로 바꾼다.
3. 초안을 쓴다. 완벽하게 쓰려 하지 말고 일단 채운다.
4. 장 단위로 커밋한다 (`01-기술명세서.md`의 커밋 규칙 참고).

## 꼭 기억할 것

이 폴더는 **공개 저장소**(Optimy-Hub, public) 안에 있습니다. 구체적인 가족 자산 규모, 실명, 계좌 정보 같은 민감한 내용은 적지 말고, 원칙과 예시 위주로 일반화해서 쓰세요. 자세한 내용은 `01-기술명세서.md`의 "보안·공개 범위" 항목을 참고하세요.
